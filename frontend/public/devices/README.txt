Pune aici PNG-urile cu iconite pentru dispozitive (fundal transparent).
Fiecare fisier trebuie sa se numeasca exact asa:

  router.png     - ruter / gateway
  laptop.png     - laptop / PC (acopera si "pc" si "laptop")
  phone.png      - telefon
  tv.png         - smart TV
  camera.png     - camera IP
  printer.png    - imprimanta
  iot.png        - dispozitiv smart home (bec, priza, hub)
  nas.png        - NAS / server (acopera si "nas" si "server")
  unknown.png    - dispozitiv necunoscut

Marime recomandata: 256x256 sau 512x512 pixeli, fundal transparent.
Daca un fisier lipseste, UI-ul afiseaza emoji in loc ca fallback.
